# VS Code

Copy [`mcp.json`](./mcp.json) to `.vscode/mcp.json` in your workspace and
replace `YOUR_AON_API_KEY` (free keys: <https://developer.aon.pro>; shared
demo key: <https://docs.aon.pro/mcp/quickstart>).

Start the server from the MCP view (or when prompted) and use it from chat in
agent mode.
