# VS Code

Copy [`mcp.json`](./mcp.json) to `.vscode/mcp.json` in your workspace and
replace `YOUR_AON_PLACEMENT_ID` with your placement ID. Create an application and a placement at <https://developer.aon.pro>, then copy
the placement ID (`plc_…`).

Start the server from the MCP view (or when prompted) and use it from chat in
agent mode.
