# Cursor

Copy [`mcp.json`](./mcp.json) to `.cursor/mcp.json` in your project (or
`~/.cursor/mcp.json` for all projects) and replace `YOUR_AON_PLACEMENT_ID` with
your placement ID. Create an application and a placement at <https://developer.aon.pro>, then copy
the placement ID (`plc_…`).

Then enable the server under **Settings → MCP**.
