# Cursor

Copy [`mcp.json`](./mcp.json) to `.cursor/mcp.json` in your project (or
`~/.cursor/mcp.json` for all projects) and replace `YOUR_AON_API_KEY`
(free keys: <https://developer.aon.pro>; shared demo key:
<https://docs.aon.pro/mcp/quickstart>).

Then enable the server under **Settings → MCP**.
